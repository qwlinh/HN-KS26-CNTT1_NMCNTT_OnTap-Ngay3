# Website Văn Phòng Phẩm

Website **bán hàng** của cửa hàng *văn phòng phẩm*.

| Thư mục | Nội dung |
|---------|----------|
| docs | file nhap_hang.txt - danh sách hàng cần nhập thêm |
| media | logo của cửa hàng |
| data | file Excel đơn bán tháng 10 |
| logs | shop.log và các file báo cáo lọc được |
| backup | bản sao logo để phòng hờ |

Lệnh liệt kê toàn bộ dự án (kể cả file ẩn):

```shell
ls -aR
```

- [x] Tổ chức lại cây thư mục và đổi tên file sang snake_case
- [x] Lọc log và tạo các file báo cáo
